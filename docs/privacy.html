Privacy Policy

Effective date: 2026-10-28

This privacy policy applies to the GreenThumb — Plant Care app (hereby referred to as "Application") for mobile devices, created by Ton Tsukanov (hereby referred to as "Service Provider") as a free, open-source service. This service is intended for use "AS IS". The source code of the Application is publicly available at https://github.com/vivogf/greenthumb-mobile.

Information Collection and Use

The Application collects only the information necessary to provide its functions:

  • Recovery key and account number — an anonymous random key created when you create an account, and an internal account number on the Service Provider's server. The key is your account key instead of an email and password. The Service Provider cannot recover this key if you lose it.
  • Plant data — plant names, species, care schedules, care dates and notes that you enter.
  • Plant photos — the cover photo of a plant and the timeline photos you add to a plant, with their captions. They are stored in Cloudflare R2 object storage in the European Union (see "Service providers" below).
  • Care journal — the care events you record for a plant (watering, fertilizing, repotting, pruning) and the journal notes you write. Achievements and streaks are calculated from this journal and stored with your account.
  • Account settings — reminder time, language, seasonal watering mode and your device's time zone. The server stores the time zone as an IANA time zone name (for example Europe/Berlin) so that reminders and "today" are calculated in your local time. The time zone is not a precise or approximate location.
  • Push notification token — issued by Firebase Cloud Messaging (FCM) and stored on the Service Provider's server only if you turn on watering reminders. It is used only to deliver reminders to your device.
  • Photos you send for species identification or plant diagnosis — these are sent through the Service Provider's server to the providers described below. The server does not store them for these features, and it does not store identification or diagnosis results. A photo is stored only if you also save it as a plant photo.
  • Crash reports and diagnostics — when the Application crashes, a crash report is sent to Firebase Crashlytics so defects can be found and fixed. A crash report contains the stack trace, device model, operating system version, app version, free memory and a random installation identifier. It does not contain your plants, photos or recovery key, and it is not linked to your account.
  • Server logs — the Service Provider's web server keeps standard access logs (IP address, time, requested address, response code and app user agent) to operate and secure the service. They are deleted after about 15 days. The server also keeps technical error logs, deleted after about 8 weeks.

The Application does not collect your name, email, phone number, age, gender, contacts, precise or approximate location, or microphone input. It does not collect analytics about your usage (screens visited, time spent). No user-tracking or advertising SDK is integrated.

The Service Provider does not use your data for marketing or send promotional messages.

Artificial Intelligence features

The Application offers two optional features that use external services. Each runs only when you start it.

  • Species identification (Pl@ntNet). The photos you choose are sent through the Service Provider's server to the Pl@ntNet identification service. Pl@ntNet processes the photos transiently to return a list of possible species. No account information is sent to Pl@ntNet.
  • Plant diagnosis (OpenAI). The photo you choose, the plant context (species, or the plant name when no species is set, the watering schedule and your optional description of the problem) and the recent care history of that plant (the type and date of the last 10 care events, without journal note text) are sent through the Service Provider's server to the OpenAI API. Requests are sent with store: false, so OpenAI does not store them for later use. OpenAI may keep request data for up to 30 days for abuse monitoring, and then deletes it. OpenAI does not use API data to train its models. No recovery key or account number is sent to OpenAI. The result is advice, not a guarantee.

Saving the recovery key to your device's password manager

After you create an account or sign in, the Application can offer to save your recovery key to your device's password manager. This is optional. On Android 13 and lower this is Google Password Manager. On Android 14 and higher it can also be another password manager that you selected in the system settings. If you accept, Android's system dialog saves the key, and that provider stores it under its own privacy policy (for Google Password Manager, in your Google account under Google's privacy policy). The Service Provider has no access to it. You can remove the entry at any time in the settings of that password manager.

Service providers

The Application and its server use the following services, each governed by its own privacy policy:

  • Cloudflare R2 — object storage in the European Union for plant cover photos, timeline photos and the private database backups. Cloudflare Privacy Policy
  • Pl@ntNet — species identification from photos, processed transiently. Pl@ntNet terms and privacy
  • OpenAI — plant diagnosis, as described above. OpenAI Privacy Policy
  • Google Firebase — three Firebase services are used: Firebase Cloud Messaging (FCM) delivers watering reminders when you turn them on; Firebase Crashlytics receives crash reports described above; Firebase Remote Config tells the Application the minimum supported app version, so an unsafe old version can ask you to update. Firebase services use a random installation identifier. Firebase Privacy Information
  • Your device's password manager (Google Password Manager, or on Android 14 and higher another password manager you selected) — only if you choose to save the recovery key, as described above. For Google Password Manager: Google Privacy Policy

The Service Provider's own server is a virtual private server that runs the backend and its database. The Service Provider does not sell, rent, or trade your information. The Service Provider may disclose information only in the following cases:

  • as required by law (subpoena or similar legal process);
  • when necessary to protect the Service Provider's rights, investigate fraud, or comply with a government request;
  • with the service providers listed above, which process data on the Service Provider's behalf.

Your choices

  • Watering reminders can be turned off in the Application's Profile tab. The push token is then removed from the server.
  • Species identification, plant diagnosis and saving the key to your password manager run only when you start them.
  • You can delete your account and data at any time (see below).

Data Retention and Deletion

The Service Provider keeps your data for as long as your account exists. Because the Application uses anonymous recovery-key authentication, the Service Provider cannot identify your data without the recovery key.

You can delete your account inside the Application: open the Profile tab, tap Delete Account and confirm. The server removes your user record, plants, cover and timeline photos, care journal, achievements and push subscriptions from its live systems immediately, and the Application removes the account data stored on your device. Copies in database backups disappear as the backups rotate. See Account & Data Deletion for the exact retention periods.

If you cannot open the Application or have lost the recovery key, you can request deletion by contacting the Service Provider at greenthumb.taunt861@passmail.net.

If you are a parent or guardian and you are aware that your child has provided personal information, please contact the Service Provider at greenthumb.taunt861@passmail.net so the Service Provider can take the necessary actions.

Security

All communication between the Application and the server, and between the server and the service providers, is encrypted with HTTPS (TLS). Photo storage and backup storage are private and are not publicly listed.

On your device, the recovery key is kept in the Application's private storage, which other apps cannot read and which is excluded from Android cloud backups and device-to-device transfer. One copy of the key is encrypted with a key held in Android Keystore. The Application also keeps your account details, including the key, in its private storage without that extra encryption, so it can work offline. The key is sent to the server only over HTTPS when you sign in.
